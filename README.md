# OplagUdregning

🇩🇰 **Dansk** | 🇬🇧 [English](#english)

Et simpelt program udviklet til at gøre beregning af oplag lettere for medarbejdere på et trykkeri.

## Formål

Projektet er udviklet ud fra et praktisk problem på et trykkeri:

- Formlen til beregning af oplag kan være svær at huske.
- En hurtig digital løsning kan gøre beregningen lettere i det daglige arbejde.
- Programmet fungerer som et simpelt alternativ til at skulle udføre beregningen manuelt.

Målet er derfor at give trykkerne et enkelt værktøj, hvor de nødvendige værdier kan indtastes, hvorefter oplaget beregnes automatisk.

## Teknologier

- Java
- JavaFX
- Maven

## Funktionalitet

Brugeren indtaster de nødvendige oplysninger for beregningen, hvorefter programmet udregner det nødvendige oplag.

Programmet er designet med fokus på at være simpelt og hurtigt at anvende i en praktisk arbejdssituation.

## Projektets baggrund

Projektet tager udgangspunkt i en reel problemstilling og er udviklet som en mindre digitalisering af en manuel arbejdsproces.

# English

🇩🇰 [Dansk](#oplagudregning) | 🇬🇧 **English**

A simple application developed to make print run calculations easier for employees at a printing company.

## Purpose

The project was developed based on a practical problem encountered in a printing environment:

- The formula used to calculate the required print run can be difficult to remember.
- A quick digital solution can simplify the calculation during daily work.
- The application provides a simple alternative to performing the calculation manually.

The goal is therefore to provide printing staff with a simple tool where the required values can be entered and the print run is calculated automatically.

## Technologies

- Java
- JavaFX
- Maven

## Functionality

The user enters the necessary values for the calculation, after which the application calculates the required print run.

The application is designed with a focus on being simple and quick to use in a practical working environment.

## Project Background

The project is based on a real-world problem and was developed as a small-scale digitalization of an otherwise manual work process.
